# Senior Solana Blockchain Engineer–Technical Assessment

## Project Context

We have an existing Solana Meme Coin project built using Solana, Rust, and Anchor.

The goal is to evaluate your ability to review blockchain architecture, identify security issues, and propose improvements for a production-ready Web3 application.

Time Limit: 60 Minutes

---

## Section 1 – Solana Fundamentals

### Question 1

Explain the difference between:

* Solana Accounts
* Programs
* PDAs (Program Derived Addresses)

Provide a practical example of how each would be used in a meme coin project.

---

### Question 2

Why might a Solana project choose Anchor Framework instead of native Solana development?

---

### Question 3

What security risks should be considered when managing a token treasury on Solana?

## Section 2 – Architecture Review

Assume the current project contains:

* SPL Token
* Wallet Connection
* Token Transfers

### Task

Provide a short technical review covering:

1. Current strengths
2. Current limitations
3. Security concerns
4. Features needed for production launch
5. Recommended next development phase

Maximum: 1 page
